Using Cursor on your phone?

Links inside Cursor chat or in-app preview often use localhost or embedded webviews that cannot download APK files. Copy your agent’s public HTTPS URL, paste it into Chrome, then open /download on that same host.

Samsung Galaxy S25 — install steps

  1. After download, open the APK from My Files → Downloads.
  2. Settings → Security → Install unknown apps — allow My Files or Chrome.
  3. Auto Blocker: Settings → Security and privacy → Auto Blocker — allow your install source or pause for this install.
  4. If you see Advanced Protection blocking the install, use Add to Home screen (PWA) from the main site instead — no sideload needed.

Prefer no sideload?
