# OGM — Open Grace Music v2.0.0

A browser-based, installable mobile app (PWA): an offline personal music
library with an in-browser MP3 converter. No accounts. Your library lives on
your device.

## What it does

- **Import audio files** from your phone (mp3, m4a, aac, ogg, opus, wav, flac, webm, mp4)
- **Import from a direct media URL** you own or are licensed to use (https, direct file link)
- **Convert to MP3 in the browser** via FFmpeg WebAssembly (first conversion downloads the encoder core from a CDN; afterwards it converts fully offline)
- **Honest offline storage** — every save is read back and verified. Tracks show a real status:
  - `PERSISTENT` (browser granted protected storage),
  - `DEVICE — may clear` (stored, but the OS can evict it),
  - `SAVE FAILED` (never silently claimed as offline)
- **Play anywhere in the app**, with queue, shuffle, seek, next/previous
- **Export/download** any track back out to your device
- **Installable** — Add to Home Screen on Android and iOS; opens fullscreen like a native app
- **Works offline** after first visit (app shell cached by the service worker)

## Integrity boundaries (by design)

- YouTube watch/share pages are **not** media files and are refused with
  guidance. For videos you uploaded yourself, download them from YouTube
  Studio first, then import the file here.
- URL import requires an explicit ownership/license confirmation.
- There is no server: nothing leaves your device except the one-time
  encoder-core download from the public CDN.

## Run it

Serve the folder over HTTPS (service workers and install require a secure
origin):

```bash
cd ogm-pwa
python3 -m http.server 8080
# open http://localhost:8080  (or deploy the folder to any static host:
# GitHub Pages, Netlify, Cloudflare Pages, your AppDeploy space, etc.)
```

## Install on mobile

- **Android (Chrome):** menu → *Add to Home screen* / *Install app*.
- **iOS (Safari):** Share → *Add to Home Screen* → *Add*.

## File map

| File | Role |
|---|---|
| `index.html` | App shell and dialogs |
| `style.css` | Warm "quiet place" theme |
| `app.js` | Library, player, verified storage, FFmpeg WASM conversion, PWA install |
| `manifest.webmanifest` | Install metadata |
| `sw.js` | Offline app shell cache |
| `icons/` | App icons (any + maskable) |
