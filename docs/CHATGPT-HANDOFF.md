# ChatGPT handoff (AppDeploy → Docker)

AppDeploy on **`https://ogm-open-grace-music-w3bpvx.v2.appdeploy.ai`** does not meet Open Grace Music production acceptance: it cannot reliably run a long-lived **`NODE_ENV=production npm start`** Express process with **ffmpeg** and **yt-dlp** on the same host, so **`GET /api/health`** often returns SPA HTML instead of **`{"ok":true,"service":"ogm-converter"}`**. Deploy instead using the repo **Dockerfile** on a capable host — **Render.com Web Service from GitHub** is the documented default ([DEPLOYMENT-PATHS.md](./DEPLOYMENT-PATHS.md)). After deploy passes [DOCKER-ACCEPTANCE-TESTS.md](./DOCKER-ACCEPTANCE-TESTS.md), set **`OGM_PUBLIC_BASE_URL`** on the server to the new HTTPS origin, then on each **PWA** and **Android** client open **Settings → Converter server URL**, paste the same base URL (no trailing slash), save, and retry a download; family members can keep using AppDeploy defaults until they update Settings or you ship a new APK with **`OGM_CONVERTER_BASE_URL`**.
